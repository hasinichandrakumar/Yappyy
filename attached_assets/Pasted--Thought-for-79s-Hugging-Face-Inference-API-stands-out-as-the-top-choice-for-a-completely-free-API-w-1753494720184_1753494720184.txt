Hugging Face Inference API stands out as the top choice for a completely free API with keys suitable for computer vision tasks like body language detection in an AI public speaking coach. It provides free access (with rate limits) to thousands of public models via an API token, including specialized ones for human pose estimation (to track posture and gestures) and facial expression recognition (to analyze emotions). You can combine multiple models in your workflow—for example, using one for pose and another for expressions—to infer overall body language. Sign up for a free account on huggingface.co, generate an API token in your settings, and use the InferenceClient library or HTTP requests to call models.

Other options with free tiers (but more limited in scope or usage) include:

SkyBiometry Face Recognition API: Free plan with 5,000 API calls per month (2,400/day limit). Supports facial emotion detection (e.g., anger, happiness, sadness) along with age, gender, and ethnicity estimation, which can help with basic body language cues from the face. No native pose or gesture detection. Get a free API key by signing up at skybiometry.com.skybiometry.com
Google Cloud Vision API: Free for the first 1,000 units (images processed) per month. Includes face detection with emotion likelihoods (joy, sorrow, anger, surprise), which aids in facial body language analysis. No direct support for full-body pose estimation or gestures. Requires a Google Cloud account and API key; enable the Vision API in the console.cloud.google.com
AWS Rekognition: Free tier for new accounts (12 months): 1,000 images per month for face analysis. Detects emotions (happy, sad, angry, etc.) via the DetectFaces API, useful for expression-based body language. Lacks built-in pose estimation. Sign up for AWS, generate API keys, and use the Rekognition service.aws.amazon.com
Face++ (Megvii): Offers free usage for all APIs, with options to upgrade based on volume (Pay As You Go). Supports emotion recognition (7 emotions like happiness, sadness) and has a Human Body API for skeleton/pose detection and gesture recognition (e.g., hand waving, standing posture). Ideal for comprehensive body language. Register for a free API key at console.faceplusplus.com.faceplusplus.com
